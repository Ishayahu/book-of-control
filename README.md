# Book of Control

Рабочий репозиторий эпического фэнтези о контроле, магическом долге и герое, который побеждает не грубой силой, а управлением допустимыми состояниями ситуации.

## Рабочий принцип проекта

Главный герой не столько преодолевает катастрофы, сколько старается не допускать, чтобы ситуация приобрела опасную для него конфигурацию.

Ключевая идея магии: магическое действие нарушает естественный баланс и создаёт локальный долг противоположного знака. Противоположные долги могут автоматически взаимозачитываться. Почти никто в мире не понимает настоящего механизма; главный герой способен воспринимать остаточный баланс и научился использовать погашение чужого долга.

## Файлы

- `world/magic-system.md` — текущая рабочая модель магии и мира.
- `characters/protagonist.md` — то, что уже известно о главном герое.
- `drafts/chapter-01.md` — тестовый художественный текст первой главы.

Все положения считаются рабочими, пока явно не отмечены как зафиксированные. Переписывание текста — нормальная часть процесса: сцены используются как полигон для проверки мира и правил.
